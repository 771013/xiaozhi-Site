# 小支租车官网高级动效设计规格

日期：2026-10-09

## 目标与范围

在稳定版本 `b6bede0` 的现有视觉结构上增强空间感、滚动节奏和交互反馈，不重建项目、不改变品牌配色和内容层级。实现需保留尚未提交但已确认的“小支官网4”横版导航 Logo、比价区地球水平镜像，以及顶部透明导航需求。

本次范围包括：导航滚动态、区块高度、非普通淡入的入场编排、车型滚动舞台、业务数据计数、小支比价悬停/键盘焦点状态、知心租背景比例，以及用户在浏览器中标注的字重和文案修正。联系我们区高度保持不变。

## 技术方案

采用原生 `IntersectionObserver`、被动滚动监听、`requestAnimationFrame` 和 CSS 合成层动画，不引入第三方动效依赖。

- 入场动画只使用 `transform`、`opacity` 和 `clip-path`，避免触发布局抖动。
- 连续滚动效果通过单个 `requestAnimationFrame` 循环更新 CSS 自定义属性或元素内联变换。
- 离散状态只在焦点车型或比价项目发生变化时更新 React state，避免滚动过程中每帧触发 React 重渲染。
- 所有动效遵循 `prefers-reduced-motion`：减少动效时直接展示最终状态、计数直接到目标值、车型区不锁定长滚动。

## 动效语言

整体使用慢节奏、非弹性的高级缓动：`cubic-bezier(.16, 1, .3, 1)`。一般入场时长为 1000–1400ms，错峰间隔为 90–140ms。

区块标题采用纵向遮罩揭示；正文使用轻微上移与去模糊；背景和大图采用小幅视差或 1.02–1.06 的缓慢缩放。禁止回弹、过冲和高频闪烁。现有按钮不增加悬停位移动效。

## 导航

- 导航继续固定在视口顶部，高度保持 70px。
- 页面位于顶部（`scrollY < 24`）时背景透明。
- 超过阈值后背景过渡到 `#006aff`，过渡时长约 700ms。
- 使用 Figma“小支官网4”节点 `649:411` 的完整横版 Logo，渲染尺寸 80×19.2944px。
- 移动端菜单沿用现有展开方式；展开时仍使用不透明蓝色面板保证可读性。

## 区块高度与背景

- Hero：720px 增加约 15%，目标 828px。
- 业务规模：746px 增加约 15%，目标 858px。
- 车型介绍：改为桌面滚动舞台，外层提供约 240–260vh 的滚动距离；内部舞台粘性停留在导航下方。
- 小支比价：916px 增加约 12%，目标约 1026px。
- 知心租：1070px 增加约 12%，目标约 1198px。
- 联系我们：保持现有 708px 和内容结构。
- 知心租背景由 `background-size: 100% 100%` 改为等比例 `cover`，以设计主体为中心校准 `background-position`，禁止横纵拉伸。

## 车型介绍滚动舞台

桌面端由页面纵向滚动驱动车型轨道持续向左移动。卡片靠近当前豪华车焦点位置时平滑放大至主卡尺寸，并提升亮度和层级；离开焦点后恢复普通卡片状态。焦点变化是连续缩放，文案切换只在最近车型改变时发生。

车型及文案：

- 豪华型：格调出众，尊享体验
- 新能源：安静高效，低碳智行
- 跑车：驾控随心，释放激情
- 商务车：宽适从容，体面出行
- 房车：一路皆景，自在安居

移动端不使用长距离粘性滚动，改为横向滑动、滚动吸附和中心卡片强调，保证触控效率和性能。

## 业务规模计数

三个数字在业务规模区首次进入视口时由 0 计数到 50000、70000、800000，持续约 1800–2200ms，使用减速曲线，保留末尾 `+`。每次页面加载只播放一次；减少动效模式直接显示目标值。

## 小支比价交互

默认焦点为“安心护航”。桌面鼠标悬停、键盘聚焦任意项目时，共用蓝色高亮块沿纵向平滑移动到目标项目；鼠标移出整个列表或焦点离开后恢复“安心护航”。移动端使用触控焦点，不依赖 hover。

- 活跃项目标题和说明文字变白。
- 图标执行蓝白互换，并使用双素材交叉淡化，避免廉价滤镜和颜色偏差。
- 蓝色高亮块采用 `transform` 移动，不改变行高，不产生布局跳动。
- 地球装饰保持 Figma 节点 `646:198` 的尺寸、透明度和混合模式，并水平镜像。

## 组件与状态

- `App` 增加导航滚动状态、比价活动索引和计数启动状态。
- 车型轨道通过 section/card refs 接收滚动进度，样式层只消费坐标、缩放、透明度和层级。
- 比价项保持语义化可聚焦元素，鼠标与键盘使用同一活动索引。
- 入场揭示使用统一类名和观察器，不引入独立动画库。

## 错误处理与降级

- `IntersectionObserver` 不可用时直接显示内容与目标数字。
- `requestAnimationFrame` 更新前检查元素引用，卸载时移除滚动监听并取消待执行帧。
- 移动端、低性能场景和减少动效模式不启用粘性车型舞台或连续视差。
- 图片加载失败仍保留现有文本内容和背景色，不影响主要信息读取。
